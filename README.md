# 🤖 AI-Powered Student Grade Management API

A production-grade RESTful API built with ASP.NET Core (.NET 10) 
combining CRUD operations with AI-powered grade analysis 
and intelligent recommendations.

## 🛠️ Tech Stack
- ASP.NET Core .NET 10 · C#
- AI-powered recommendation engine
- REST API / OpenAPI
- Azure-ready deployment
- Microservices architecture

## 📡 API Endpoints

### Student Management
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/student | Get all students |
| GET | /api/student/{id} | Get student by ID |
| POST | /api/student | Add new student |
| PUT | /api/student/{id} | Update student |
| DELETE | /api/student/{id} | Delete student |

### 🤖 AI Analyzer
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/aianalyzer/analyze | AI grade analysis |
| GET | /api/aianalyzer/recommendations | Smart recommendations |
| GET | /api/aianalyzer/performance-report | Full AI report |
